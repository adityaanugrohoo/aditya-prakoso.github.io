# Aditya Nugroho Prakoso — Personal Portfolio

A responsive, single-file portfolio site. It uses inline CSS/JavaScript and Google Fonts. The profile avatar first loads from the public GitHub profile image URL and retries the GitHub avatar endpoint if needed. If both endpoints fail, a designed AP fallback keeps the portrait area from becoming blank. For a real locally hosted portrait, add your own photo file and update the image path in `index.html`.

## Publish with GitHub Pages

1. Open https://github.com/adityaanugrohoo/aditya-prakoso.github.io
2. Choose **Add file → Upload files** and upload `index.html` from this folder to the repository root. Commit the change to `main`.
3. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, set branch to `main` and folder to `/(root)`, then Save.
4. GitHub Pages will display the live address in Settings → Pages once deployment completes. Because this repository is named `aditya-prakoso.github.io` rather than exactly `adityaanugrohoo.github.io`, its likely URL is `https://adityaanugrohoo.github.io/aditya-prakoso.github.io/`.
